# Petabyte Wiki

New-user documentation for Petabyte — the GPU-compute marketplace. Start with
**[index.md](index.md)**.

The same pages are served in the running app at **`/wiki`**, rendered in Petabyte's Scalar docs
environment (the one that powers the API reference at `/docs`).

## Contents

- [Overview & architecture](overview.md) — what Petabyte is and how the pieces fit
- [Getting started](getting-started.md) — 5-minute paths for buyers and sellers
- [For buyers](buyers.md) — rent GPUs, run jobs, VMs, clusters, storage
- [For sellers](sellers.md) — earn from a GPU with the agent
- [CLI](cli.md) — the `petabyte` command line
- [Models](models.md) — discover, download and run open models
- [Persistent storage](storage.md) — incremental volumes that outlive a VM
- [Teams & security](teams-and-security.md) — roles, API keys, 2FA, audit log
- [Payments & trust](payments-and-trust.md) — escrow, TEST MODE, the trust ladder
- [API & keys](api.md) — the Scalar portals, scopes, auth
- [Self-hosting](self-hosting.md) — run and configure your own Petabyte
- [Glossary](glossary.md) — terms in one place

Deeper technical references (runbooks, trust model, disk rental, models, storage) live in the
repo's [`docs/`](../docs) folder.
